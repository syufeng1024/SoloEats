# 订单接口联调与验收

> 接口：`POST /api/v1/orders`
> 关联模块：`solo-eats-app`、`solo-eats-order`、`solo-eats-product`、`solo-eats-marketing`
> 测试环境：MySQL 3307、Redis 6379、RabbitMQ 5672

## 1. 前置数据

执行 V2 脚本，准备 SKU、库存和优惠券：

```powershell
Get-Content .\solo-eats-app\src\main\resources\db\migration\V2__sku_and_demo_data.sql -Raw |
  docker exec -i solo-eats-mysql mysql -usolo -p<MYSQL_PASSWORD> solo_eats
```

## 3. 创建订单

```powershell
curl.exe -X POST http://localhost:8080/api/v1/orders `
  -H "Content-Type: application/json" `
  -H "Idempotency-Key: demo-20261021-001" `
  -d '{
    "userId": 1,
    "merchantId": 1,
    "shopId": 1,
    "fulfillmentType": 2,
    "couponId": 3001,
    "packagingFee": 200,
    "deliveryFee": 0,
    "pickupPhone": "13800000000",
    "remark": "integration test",
    "items": [
      { "skuId": 1001, "quantity": 2 }
    ]
  }'
```

本次实测响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "orderId": 1,
    "orderNo": "SO20261021093327A8F5D490",
    "status": 0,
    "fulfillmentType": 2,
    "goodsAmount": 5600,
    "packagingFee": 200,
    "deliveryFee": 0,
    "discountAmount": 500,
    "platformDiscount": 500,
    "merchantDiscount": 0,
    "payAmount": 5300,
    "pickupCode": null,
    "items": [
      {
        "skuId": 1001,
        "skuName": "招牌牛肉面",
        "quantity": 2,
        "unitPrice": 2800,
        "originalAmount": 5600,
        "discountAmount": 500,
        "payableAmount": 5100
      }
    ]
  },
  "traceId": "..."
}
```

字段口径：

| 字段 | 计算 |
|---|---|
| `goodsAmount` | `SKU price × quantity` 之和 |
| `discountAmount` | 优惠券优惠金额，平台券计入 `platformDiscount`，商家券计入 `merchantDiscount` |
| `payAmount` | `goodsAmount + packagingFee + deliveryFee - discountAmount` |
| `status` | 0 = `WAIT_PAY`，下单只锁库存，不扣款 |

## 4. 数据库校验

把 `<orderId>` 替换为响应中的 `orderId`：

```sql
SELECT id, order_no, status, goods_amount, packaging_fee, delivery_fee,
       discount_amount, platform_discount, merchant_discount, pay_amount
FROM t_order WHERE id = <orderId>;

SELECT sku_id, quantity, original_amount, discount_amount, payable_amount
FROM t_order_item WHERE order_id = <orderId>;

SELECT sku_id, available_qty, locked_qty, sold_qty
FROM t_sku_stock WHERE sku_id = 1001;

SELECT order_id, sku_id, qty, status
FROM t_stock_lock WHERE order_id = <orderId>;

SELECT biz_type, biz_id, sku_id, op, qty, before_available, after_available
FROM t_stock_log WHERE biz_id = <orderId>;

SELECT id, status, order_id FROM t_user_coupon WHERE id = 3001;

SELECT discount_type, source_id, bearer, amount, apportion_json
FROM t_order_discount WHERE order_id = <orderId>;

SELECT order_id, from_status, to_status, event, operator_type, operator_id, request_id
FROM t_order_status_log WHERE order_id = <orderId>;
```

本次实测结果：

| 表 | 结果 |
|---|---|
| `t_order` | status=0，goods=5600，packaging=200，discount=500，pay=5300 |
| `t_order_item` | quantity=2，original=5600，discount=500，payable=5100 |
| `t_sku_stock` | available=98，locked=2，sold=0 |
| `t_stock_lock` | qty=2，status=0（锁定） |
| `t_stock_log` | ORDER / LOCK / qty=2 / before=100 / after=98 |
| `t_user_coupon` | status=1（已锁定），order_id=1 |
| `t_order_discount` | platform bearer=1，amount=500，apportion=`{"1001":500}` |
| `t_order_status_log` | from=-1，to=0，event=CREATE，request_id=幂等键 |

## 5. 幂等验证

用同一个 `Idempotency-Key` 重复提交同一请求：

```powershell
curl.exe -X POST http://localhost:8080/api/v1/orders `
  -H "Content-Type: application/json" `
  -H "Idempotency-Key: demo-20261021-001" `
  -d '{ ... 同一请求体 ... }'
```

实测结果：

```json
HTTP 409
{"code":40004,"message":"请求处理中","data":null,"traceId":"..."}
```

说明：P0 的 `@Idempotent` 用 Redis 阻止重复提交，不返回首次响应；需要“重复请求返回首次订单”时，按 TDD 3.4 接 `t_idempotency` 响应回放。

## 6. 清理测试数据

仅本地使用。先删除订单相关行，再重跑 V2 重置库存和券：

```sql
DELETE FROM t_stock_log WHERE biz_id IN (SELECT id FROM t_order WHERE remark = 'integration test');
DELETE FROM t_stock_lock WHERE order_id IN (SELECT id FROM t_order WHERE remark = 'integration test');
DELETE FROM t_order_discount WHERE order_id IN (SELECT id FROM t_order WHERE remark = 'integration test');
DELETE FROM t_order_item WHERE order_id IN (SELECT id FROM t_order WHERE remark = 'integration test');
DELETE FROM t_order_status_log WHERE order_id IN (SELECT id FROM t_order WHERE remark = 'integration test');
DELETE FROM t_order WHERE remark = 'integration test';
```

然后重新执行 V2 SQL，恢复 `t_sku_stock` 和 `t_user_coupon`。
