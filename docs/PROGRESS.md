## 怎么复核

进度**唯一正本是各任务卡末尾的「执行记录」**，配合 Git 提交历史。需要重新核实时代码层面这样查：

```bash
# 模块是否建了
grep -c '<module>' pom.xml                        # 期望 14，P1 全做完应是 16
ls -d solo-eats-service solo-eats-content         # 目前两个不存在

# 数据库演进到哪一版
ls solo-eats-app/src/main/resources/db/migration/*.sql | wc -l   # 期望 24（V24）

# 接口规模
ls solo-eats-app/src/main/java/com/soloeats/app/controller/*.java | wc -l   # 期望 63

# 前端页面数
grep -c '"path"' solo-eats-uniapp-user/src/pages.json      # 11（阶段A 目标）
grep -c '"path"' solo-eats-uniapp-rider/src/pages.json     # 8
grep -c '"path"' solo-eats-uniapp-merchant/src/pages.json  # 8
find solo-eats-web/src/views -name '*.vue' | wc -l         # 7（含 NotFound，业务页 6）

# 各卡执行记录有无
grep -n '执行记录' -A 6 docs/tasks/T05-*.md
```

## 维护约定

- 每完成一个会话单元：更新**对应任务卡**的「执行记录」，再同步本文档的两张表。
- 一个会话单元一个 commit，信息格式 `feat(T03-A): ...`。
- 状态口径：`done` = 代码 + 编译 + 提交 + 执行记录全齐；`doing` = 有未提交/未验证；`todo` = 未派发。
- 本文档只记录**结论与依据**，具体实现细节看任务卡。
